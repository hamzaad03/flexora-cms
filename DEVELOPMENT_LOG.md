## 2026-10-27 — Admin rebrand: FlexoraCMS logo, favicon, theme and dashboard
- **Commit:** `PENDING COMMIT` — not yet committed; replace with the real full hash and exact subject immediately after the commit is made.
- **Phase/issue:** Admin UI (outside the numbered roadmap; based on the "FlexoraCMS Brand and Dashboard Showcase" design) / no issue or PR
- **Summary:** New brand mark and logo (`src/components/brand/flexora-logo.tsx`), app icon (`src/app/icon.svg`), and generated `favicon.ico` (16/32/48 px) plus `apple-icon.png`. Plus Jakarta Sans font and brand palette tokens with a navy dark mode (next-themes, with a toggle in the top bar). The admin shell was redesigned: branded sidebar with permission-filtered "Quick access", sticky top bar with content search (⌘/Ctrl+K), "View website", theme toggle, and a user menu showing name and role, plus a mobile navigation sheet. The dashboard was rebuilt with real data only: total pages and posts (with the number added in the period), unique visitors and conversion rate (non-spam form submissions ÷ visitors) compared with the previous period, a 7/30-day visitors chart (SVG, hover/keyboard tooltip, screen-reader table), quick actions, recent content, and top pages with change. Each section is gated by `content.view` / `analytics.view`. Added the `/admin/search` page and `searchEntries()` (title search across content types). Fixed the Analytics nav icon (`bar-chart-3` isn't in lucide's canonical `icons` map, so it had rendered a placeholder circle). Login and setup screens use the new logo; doubled page-title suffixes were fixed.
- **Files/modules:** `src/app/layout.tsx`, `src/app/globals.css`, `src/app/icon.svg`, `src/app/apple-icon.png`, `src/app/favicon.ico`, `src/app/admin/(protected)/{layout,page}.tsx`, `src/app/admin/(protected)/search/page.tsx`, `src/app/admin/(protected)/forbidden/page.tsx`, `src/app/admin/login/page.tsx`, `src/app/setup/page.tsx`, `src/components/brand/flexora-logo.tsx`, `src/components/theme-provider.tsx`, `src/components/admin/{sidebar,topbar,user-menu,nav-items}.tsx|ts`, `src/components/admin/dashboard/{format,visitors-chart}.tsx`, `src/server/services/{dashboard,content}.ts`.
- **Database:** None (no schema change). The dashboard uses two read-only parameterized raw queries (`COUNT(DISTINCT …)`, `DATE(created_at)`) on `page_views`, written for MySQL.
- **Security:** Dashboard sections and search are permission-gated server-side (`content.view`, `analytics.view`). Search input is capped at 200 characters and goes through Prisma parameters; raw SQL uses tagged-template parameters only. No new public endpoints.
- **Tests run:** `npm run typecheck` — no errors. `npm run lint` — no errors or warnings after fixing one `react-hooks/set-state-in-effect` error and one unused variable. `npm test` — 6 files, 36 tests passed. `npx prettier --check src` — passed. `npm run build`, with CI's dummy env — compiled successfully; it reports one Turbopack "whole project traced" warning on `next.config.ts`, which was already present before this change (an earlier build had copied a root-level PNG into `.next/standalone`). Chart colors were checked with the dataviz palette validator: `#2563EB` on light passes all checks; for dark, `#60A5FA` failed the lightness band, so `#4F8BF7` was used and passes. **Not run:** Playwright E2E, and the dashboard was not viewed in a browser, because no MySQL is available on this machine.
- **Deployment/operations:** None. The Plus Jakarta Sans font is fetched by `next/font` at build time, as Geist was before.
- **Known limitations:** No new unit tests cover the dashboard service or chart. Day buckets are UTC. "Conversion rate" counts every non-spam form submission as a lead. The design's notifications bell, site switcher and "Need help?" card were left out, because there is no notifications system, multi-site support or docs URL yet. The code uses the "FlexoraCMS" brand name in the UI, while the docs still say "FlxOraCMS" (needs an owner decision). The source design PNG at the repo root is untracked.
- **Follow-up:** Visual check in light and dark mode on desktop and mobile with a seeded MySQL database; run Playwright; add unit tests for `pctChange`, `formatRelative` and day-bucket filling; decide the canonical product name; move the design PNG to `docs/brand/` or keep it out of git.
